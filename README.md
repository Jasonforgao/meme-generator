# 🎭 梗图生成器

一个纯前端运行的表情包/梗图生成工具，可在 **Android 手机** 和 **Mac 电脑** 的浏览器中直接使用。上传带有人物的图片或视频，AI 会自动识别表情并生成多个风格的静态/动态表情包。

## ✨ 功能特性

- 📸 **图片/视频上传**：支持 JPG、PNG、GIF、MP4、MOV 等常见格式
- 😊 **人物识别与表情分析**：基于 `face-api.js` 本地识别人脸，无人物时提示不采纳
- 🎨 **多风格生成**：经典上下字、沙雕吐槽、震惊体、社死现场、阴阳怪气、可爱治愈、电影字幕 7 种风格可选
- 📝 **热梗文案匹配**：根据识别到的表情自动匹配中文网络流行语与笑点
- ✏️ **文案可编辑**：AI 生成推荐文案后，用户可自由修改再合成
- 🧠 **人脸避让布局**：文字会自动避开人脸区域，优先放在顶部或底部安全区，减少遮挡
- 🖼️ **静态 + 动态输出**：支持 PNG 静态图和 GIF 动态图
- 📷 **支持拍照**：可直接调用摄像头拍摄素材
- 🔒 **本地运行**：人脸模型与素材均不上传服务器，保护隐私

## 🚀 使用方法

### Mac 电脑

1. 用浏览器（推荐 Chrome / Safari）打开项目目录下的 `index.html`
2. 点击「选择文件」上传图片或视频，也可以拖拽文件到上传区
3. 等待 AI 识别完成，选择喜欢的风格
4. 在「生成结果」中切换静态图/动态 GIF，点击「保存到本地」

### Android 手机

#### 方式一：安装为 PWA 应用（推荐）

1. 将项目部署到局域网静态服务器（见下方「局域网共享」）
2. 用 Chrome 打开访问地址，点击浏览器菜单 →「添加到主屏幕」/「安装应用」
3. 安装后，手机桌面会出现「梗图生成器」图标，点击即可像原生 App 一样全屏运行
4. 支持离线使用（首次加载后，核心资源会被缓存）

#### 方式二：从相册直接导入

打开应用后，有两种方式导入照片/视频：

- **从应用内选择**：点击「选择文件」，在弹出的文件选择器中选择「相册/图库」，即可选取图片或视频。
- **从相册分享导入（最方便）**：在安卓相册中打开某张照片/视频，点击「分享」按钮，选择「梗图生成器」图标，应用会自动接收并进入识别流程。

#### 方式三：直接拍照

点击「拍照」按钮，授权摄像头权限后可直接拍摄人物照片。

#### 保存表情包

生成结果后，点击「💾 保存静态图」或「💾 保存动态图」，即可将表情包保存到手机相册。

### 局域网共享（推荐手机使用）

如果想在手机上方便访问，可以在 Mac 上启动一个本地静态服务器：

```bash
# 进入项目目录
cd meme-generator

# 如果有 Python 3
python3 -m http.server 8080

# 如果有 Node.js
npx serve .
```

然后在手机浏览器访问 `http://<Mac 的 IP 地址>:8080` 即可。

## 🔥 热梗每日自动更新

本工具支持每天根据网络热点自动更新表情包文案：

### 工作原理

1. 工具启动时会自动拉取你配置的热梗 JSON 文件（默认使用内置 `hot-topics.json`）
2. 生成文案时，**2/3 的概率**会把当前热梗融入文案，1/3 概率使用内置 490 条文案库
3. 拉取成功的 JSON 会在本地缓存 24 小时，下次访问优先用缓存
4. 拉取失败时自动回退到内置文案库

### 如何每日更新热梗

#### 方式 A：维护自己的 JSON 文件（推荐）

1. 复制项目内的 `hot-topics.json` 到任意网络可访问的位置（如阿里云 OSS、GitHub raw、Gitee）
2. 每天编辑该 JSON，加入当天网络热梗
3. 在工具的「🔥 网络热梗库」设置区粘贴该 URL，点击「刷新」
4. JSON 格式示例：

```json
{
  "topics": [
    "今日热搜：xxx",
    "全网刷屏：xxx",
    "新梗：xxx"
  ]
}
```

#### 方式 B：使用微博/知乎/百度热搜 API

由于浏览器 CORS 限制，前端无法直接拉取微博等平台的官方热榜 API。你需要：

- 写一个后端服务（如 Node.js + Express）代理拉取热榜
- 或使用云函数（阿里云函数计算、腾讯云 SCF）做代理
- 让后端返回符合上述 JSON 格式的热梗列表

#### 方式 C：手动在工具内输入热梗

打开工具页面，在「🔥 网络热梗库」输入框内粘贴任何热梗词，点击「刷新」即可融入生成。

## 🧠 技术说明

- **人脸检测**：`tiny_face_detector_model`
- **人脸关键点**：`face_landmark_68_model`
- **表情识别**：`face_expression_model`，可识别平静、开心、难过、生气、惊讶、害怕、厌恶 7 种表情
- **动态 GIF**：使用本地 `gif.js` 在浏览器端合成（避免跨域 Worker 限制）

## ⚠️ 使用提示

- 首次打开会下载 AI 模型（约 1MB），请保持网络畅通
- 为保证识别效果，请使用**正面、光线充足、人物清晰**的照片
- 动态 GIF 生成需要一定计算资源，复杂图片可能需要几秒时间
- 由于浏览器安全策略，本地直接打开 `file://` 协议时部分功能可能受限，建议通过 `http://localhost` 访问
